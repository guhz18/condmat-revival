## 1. 对象和证据

身份至少为composition + polymorph/space group + stoichiometry/doping + bulk/film + relevant condition。保留作者原式与人工核实的aliases；约分式相同不能自动合并晶相。

每个事实有source ID、DOI/arXiv/原文URL、所读层次（全文/摘要/元数据/补充表）、页/节/表/图位置、核查日期、证据是否直接。优先原始论文；未取得全文时不捏造Methods内容。年份写最早找到的已核验实验年，不自动称首报。

每次检索记录原query、source、filters、日期窗口、access time、分页/上限、reported_total可null、真实retrieved_count、result IDs及status。状态采用complete_for_query / partial / failed / manual / blocked（数据库可将blocked保存为failed并在details说明）。无结果与未检索/失败严格区分。不要记录keys、cookies和私密会话链接。

## 2. 热度

默认W=最近90天，B=紧接此前365天。按最早公开日，非网页更新日或arXiv修订日。不同索引混合时先统一同一份语料/查询边界。DOI/arXiv关联去重，标题相同仅提示审核，不自动认定同一工作。

保存nW、nB及凝聚态对应领域总量NW、NB。可比较主题份额nW/NW和nB/NB；平滑增长可用：

`log2(((nW+0.5)/(NW+1))/((nB+0.5)/(NB+1)))`

没有领域分母时仅展示输入样本的日均发文变化：

`log2(((nW+0.5)/90)/((nB+0.5)/365))`

0.5是可调平滑，不是物理常数。nW<5标低样本。字段/主题词跨窗口变化须重算。截断、检索排名样本、日期大量缺失不能用于全领域定量排名。新闻转载一篇研究只算一条研究事件；研究团队数需身份核验。引用增长需时间快照，不能拿累计引用当近期增长。

热点分数是下面的启发式判断，可在scout模式给出有来源的分级；必须写judgment，不包装成客观计量。无法支持某维则null并保留分项。

## 3. 单晶等级

| 等级 | 必须具备的证据 | 定位 |
|---|---|---|
| C0 | 仅计算/身份不明 | 不作单晶实验推荐 |
| C1 | 粉末/薄膜/形态未明 | 观察 |
| C2 | 明确单晶实验，生长细节未完整核验 | 可评估但有复现缺口 |
| C3 | 方法、关键条件和尺寸/质量有可定位原文 | 优先 |
| C4 | C3且匹配用户已知实验条件 | 最可操作 |

单晶结构测定小晶粒不保证足以做输运、比热、ARPES或中子散射。历史成功不保证今天可复现；同族生长不能填补本材料未知。single crystal evidence必须对应同一相。

## 4. 查新与资格

分别保留材料全部问题近5年、材料×目标问题近5年、目标问题全历史。精确数量只来自真正枚举、去重后的记录；搜索引擎估计值不等于论文数。默认近5年<=5项独立直接工作为“少量”的候选启发式，按子领域校准，不以缺检当稀缺。

主推荐门槛：

1. 历史实验年达到20年，身份/相明确。
2. C2以上且来源已读。
3. 有具体机制联系、可检验问题和支持证据。
4. 至少两个互补来源和前/后向引用链完成限定查新，并做Scholar补检。
5. 没有已知成熟同条件同问题、明显错误匹配等反证。

Scholar浏览器manual检索可以满足“已补检”，但不能使语料成为全量；记录实际看过的页和记录数。blocked/failed/not_attempted不能满足补检。多个来源不保证无遗漏，主推荐仍只称范围内机会。

有缺口放观察名单；已热门或已成熟放基准/排除。无主推荐是允许的。不要从一篇新文献断言首次（尤其应查老的高压/多晶文献）。

## 5. 评分

用0–5分，允许0.5刻度但不制造不必要精度。每维必须有理由与证据，未知=null，不等于0。可显示已知分项，但缺关键维度时不算总分。评分是研究决策的透明启发式，不是成功概率或已校准科学标准。默认权重可按用户实验条件调整。

### 热点 H（0–100）

`H = 20 × (0.40 I + 0.35 M + 0.15 F + 0.10 B)`

- **I物理重要性**：是否触及重要未解机制/概念，能否区分竞争理论，结果对凝聚态有何可推广意义。0无清晰问题；3明确开放问题；5有关键可证伪判断且潜在概念影响广。
- **M近期动量**：当前窗口独立成果/实验进展是否上升。0持续无新实质线索；3有当前独立进展；5多项互补原始进展。精确增长需audit语料，scout用注明出处的定性判断。
- **F实验切入可行性**：是否存在历史单晶平台和可实施测量，用户条件已知则匹配；未知不能假设。
- **B证据广度**：独立研究/方法/机构与理论实验覆盖；避免转发数量冒充独立性。

“H高”不意味“材料竞争小”。若只指定话题，不必做跨领域H排名；可以给其分项评估和限制。

### 材料 P（0–105）

`P_base = 20 × (0.45 I + 0.35 F + 0.10 N + 0.10 E)`
`P = P_base + SC`，SC为0–5附加分。

- **I物理重要性**：材料是否能承载并区分热点关键机制；仅“有同样晶格/元素”不够。3有合理明确机制桥接；5目标相已有关键要素且实验可判别核心问题。
- **F实验可做性**：样品获取、单晶证据、制备难度、尺寸/质量、测量设备和时间成本。易获取且实验简单可高分；高压/长周期/易分解可降低。可以现有证据评估，不为打分提前全量合成调研。
- **N问题层面的稀缺性**：0已充分研究；3有限直接工作与明确剩余问题；5限定多源审计未检出直接工作且覆盖可靠。覆盖不足=null，不能给高分。
- **E证据质量**：身份、历史、单晶、匹配、反证的来源质量与一致性；区分摘要线索和已读方法。
- **SC超导加分**：0无证据；1–2明确同族/机制线索；3本材料在特定条件有可信报告；4–5与拟研究问题高度相关的直接体相证据。Nb探针、邻近效应不能冒充本材料本征超导。

实验可做性细则（只用已经核验的信息）：
- 5：有近期明确可获取样品线索且目标实验适配，或用户已复现成熟生长。
- 4：明确单晶生长、方法及尺寸符合需求，无已知严重实验瓶颈；供样仍应单独标“待确认”。
- 3：单晶文献充分但有可解决的设备/质量/稳定性障碍。
- 2：仅旧单晶证据，路线/尺寸不全，或需较难条件。
- 1：存在严重已知障碍；0：已知无法满足目标实验。
- 未知设备并非永远无法评估，但必须写清采用的条件假设；若条件会改变分值，给条件化分项而不是伪精确总分。

一个候选可呈现“重要性4.5，可做性2.0，查新未完成，总分暂不生成”。总分不同于入选资格；不能让奖励抵消缺证据。

基准/排除材料有直接同问题已发表证据和理由时，可在查新尚未全面完成的情况下给N=0；已确认存在同类工作足以支持该低分。此例外不能用于正向稀缺分或把未知当0。同等证据不要凭直觉拉开不同材料的分数；解释比较基准与本轮评分版本。

## 6. 合成与供样

screening只记录已有证据中的who/where与获取状态。作者贡献写明crystal growth则可署“生长责任作者”；否则仅称该论文团队。当前供样只能有公开说明/用户提供的确认作为证据；“曾发表”不等于“可要到”。私人通信仅在用户提供时使用，不编造，不擅自联系。

synthesis按所选材料逐一进行，不能预先处理全部。列原文来源/定位、材料相、方法、配料、设备/容器/气氛、温程、时间、后处理、尺寸/质量、失败点、替代路线和本实验室差距。未知参数留空，不给缺来源的精确温度/压力/计量。区分文献配方和待验证改进。

## 7. 验收

每个卡片有一两句入选理由、重要性与可做性、单晶等级、生长团队与获取状态、主要出处、后续展开指令。详情才放长证据链。事实/解释/假说分开，最小区分实验与竞争机制齐全。0篇必须是真实成功检索；未读全文、Scholar受阻、合成未展开全部可见。原始数据库保存版本与失败轨迹，不能只剩漂亮报告。
